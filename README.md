# GEO-монитор · статический снапшот

Зашифрованный снимок GEO-монитора от 06.11.2026: видимость бренда Skillbox
в ответах нейросетей, источники цитирования, конкуренты, переходы из
ИИ-поиска и очередь рекомендаций по двум проектам.

Доступ — по ссылке с ключом (часть после `#k=`). Ключ расшифровывает
данные в браузере (AES-256-GCM) и на сервер не передаётся.

## Как обновить снапшот

Снапшот собирается из рабочего проекта командой сборки `build_snapshot.py`
(рендер GET-экранов на реальной базе, gzip, шифрование, публикация).
Обновление — новый прогон сборки и push в этот репозиторий.

## Структура

- `index.html` — публичная оболочка и экран блокировки;
- `assets/app.css` — дизайн-система интерфейса (публичная, без данных);
- `assets/router.js` — загрузчик и навигатор по зашифрованным страницам;
- `p/*.enc` — зашифрованные страницы (ключ только у команды).
